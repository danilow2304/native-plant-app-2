# Native Plant App
Full-stack app: React (Vite) -> Express API -> MongoDB.

- Database name: nativePlantDB
- Collection name: plants
- Features: view, search, add, edit, delete plants
## Run it
1. mongod --dbpath ./server/data
2. cd server && node server.js (runs on port 5001)
3. cd client && npm run dev (runs on port 5173)
